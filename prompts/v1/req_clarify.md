评分规则：
+2: 高度一致  +1: 基本一致  0: 中性  -1: 轻微冲突  -2: 明确冲突

输出格式（TSV格式）：
必须使用 TSV（制表符分隔值）格式输出结果。第一行必须是表头，后续每行包含一条需求的评分结果。

TSV 格式必须为：
```
需求ID	理由	评分
REQ-001	简短理由30字内	+1
REQ-002	简短理由30字内	-1
```

要求：
- 使用**制表符**作为列分隔符（不要使用逗号、空格或竖线）
- 第一行必须是表头：`需求ID	理由	评分`（列之间用制表符分隔）
- 每条数据行必须包含三列，用制表符分隔：
  - 第1列：需求ID（如 REQ-001）
  - 第2列：理由（简短理由30字内，引用基准SRS中的明确证据，指出需求与基准SRS的一致/不一致点，不给建议）
  - 第3列：评分（必须是以下之一：+2, +1, 0, -1, -2）
- 理由列可以包含逗号、分号等任何标点符号 - 只有制表符用作分隔符
- 必须覆盖所有需求，不能遗漏
- 不要在 TSV 格式之外包含任何额外的文字说明、空行或注释

请逐条评分。
