# 提示词版本 2（中文）

## 概述

版本 2 提示词是增强版本，旨在提升关键评估维度的表现：
- 业务流程完整性
- 异常处理覆盖度
- 数据与状态完整性
- 一致性/冲突检测

## 主要改进

### req_explore.md
- 在补充新需求时，明确要求关注四个关键维度
- 强调业务流程、异常处理、数据模型和一致性检查
- 提供每个维度的详细指导

### req_clarify.md
- 增加了一致性和完整性的额外评估标准
- 表现出一致性和完整性的需求会获得更高评分
- 增强评分理由，考虑跨需求验证

### doc_generate.md
- 添加了必需的文档结构章节：
  - 业务流程描述
  - 异常处理章节
  - 数据模型章节
  - 一致性保证
- 确保全面覆盖所有关键维度

### req_parse.md
- 与 v1 版本保持一致（无变化）

## 使用方法

运行系统时设置提示词版本：
```bash
python main.py input.txt --prompt-version v2
```

或设置环境变量：
```bash
export PROMPT_VERSION=v2
python main.py input.txt
```

使用 v2 提示词后，您应该看到：

- 增强的需求一致性
- 在业务流程、异常处理、数据状态和一致性维度上的更高得分
